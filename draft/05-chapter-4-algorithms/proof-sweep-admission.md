# Доказательство: оптимальность фазы заполнения по приёму в порядке приоритета

**Теорема 4.1 (оптимальность заметания по приёму в порядке приоритета).** Пусть задачи упорядочены по невозрастанию приоритета $c_1 \geq c_2 \geq \dots \geq c_N$ и каждая задача $i$ характеризуется минимальным объёмом ресурса $x_{\min,i}$. Жадный алгоритм фазы заполнения, принимающий задачу $i$ тогда и только тогда, когда $x_{\min,i}$ не превосходит оставшейся ёмкости, возвращает допустимый набор принятых задач, **лексикографически максимальный** в порядке приоритета: для любого другого допустимого набора $S$ (с $\sum_{i\in S} x_{\min,i} \leq C$) вектор индикаторов принятия набора, выдаваемого жадным алгоритмом, не меньше вектора $S$ в лексикографическом смысле. В частности, жадный алгоритм максимизирует число принятых задач среди всех допустимых наборов, лексикографически наилучших по приоритету. Вычислительная сложность фазы — $O(N \log N)$.

## Доказательство

Пусть $G$ — набор задач, принятых жадным алгоритмом, и $T$ — произвольный допустимый набор ($\sum_{i\in T} x_{\min,i} \leq C$), $T \neq G$. Заметим, что фаза заполнения впервые возвращает допустимый набор: на каждом шаге суммарный минимальный объём принятых задач не превосходит $C$ по построению.

Предположим противное: $T$ лексикографически больше $G$, то есть вектор индикаторов $T$ превосходит вектор $G$ в первой позиции, где они различаются. Пусть $k$ — первый индекс (в порядке убывания $c_i$), для которого индикаторы различаются. Тогда $k \in T$ и $k \notin G$, а для всех $i < k$ индикаторы совпадают.

Поскольку жадный алгоритм не принял задачу $k$, в момент её рассмотрения оставшаяся ёмкость была строго меньше $x_{\min,k}$:

$$\sum_{i \in G,\; i < k} x_{\min,i} + x_{\min,k} > C.$$

Но наборы $G$ и $T$ совпадают на всех $i < k$, значит

$$\sum_{i \in T} x_{\min,i} \geq \sum_{i \in T,\; i \leq k} x_{\min,i} = \sum_{i \in G,\; i < k} x_{\min,i} + x_{\min,k} > C,$$

что противоречит допустимости $T$. Следовательно, ни один допустимый набор не лексикографически больше $G$; набор $G$ лексикографически максимален.

Из лексикографической максимальности непосредственно следует максимум числа принятых задач среди лексикографически наилучших наборов: лексикографическое упорядочение отдаёт приоритет включению старших по приоритету задач, а среди наборов, совпадающих на всех старших задачах, — включению следующих, что в итоге даёт максимально возможное число принятых задач при данном приоритетном порядке.

**Оценка сложности.** Сортировка по убыванию $c_i$ выполняется за $O(N \log N)$; один проход по задачам с поддержанием остатка ёмкости — за $O(N)$. Итоговая сложность фазы заполнения — $O(N \log N)$.

∎

## Комментарий к целям

Утверждение теоремы касается **приёма** (числа размещённых задач в порядке приоритета), а не взвешенного объёма $\sum_i c_i x_i$. Для цели $\max \sum_i c_i x_i$ фаза заполнения, как показано контрпримером в §4.3 ($C=100$, задача A $(c=100,\ x_{\min}=40,\ x_{\max}=100)$, задача B $(c=95,\ x_{\min}=60,\ x_{\max}=60)$: алгоритм даёт $9700$, оптимум $10000$), неоптимальна; точная оптимизация взвешенного объёма требует ЛП-подхода §3.5. Лексикографический характер жадного приёма — ключевое отличие от задачи о ранце: наличие нижней границы $x_{\min}$ делает жадное заполнение приёмом-оптимальным, но не объём-оптимальным.
