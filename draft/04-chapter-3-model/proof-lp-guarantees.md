# Доказательство: свойства ЛП-релаксации — разрешимость, верхняя оценка оптимума, квоты справедливости

Файл-источник: `draft/04-chapter-3-model/README.md`, §3.5.

## Постановка

Рассматривается задача размещения эластичных задач по приоритету в пределах ёмкости с ЛП-релаксацией:

$$\max_{x} \sum_{i=1}^{n} c_i \sum_{l=1}^{m} x_{i,l},$$

при ограничениях

$$\sum_{l=1}^{m} x_{i,l} \leq 1, \quad \forall i,$$

$$\sum_{i=1}^{n} \sum_{l=1}^{m} x_{i,l} \cdot l \cdot p_i(l) \leq C,$$

$$x_{i,l} \geq 0, \quad \forall i, l,$$

где $p_i(l)$ — время обработки задачи $i$ на $l$ процессорах, $c_i$ — приоритет задачи, $C$ — бюджет ёмкости. ЛП-релаксация допускает частичное размещение ($0 \le \sum_l x_{i,l} \le 1$).

## Теорема 3.1 (полиномиальная разрешимость и верхняя оценка оптимума ЛП-релаксации)

1. **Разрешимость.** ЛП-релаксация решается за полиномиальное время по размеру входа.
2. **Верхняя граница.** Оптимум релаксации $V_{LP}$ не меньше оптимума исходной целочисленной задачи $V_{IP}$: $V_{LP} \geq V_{IP}$.
3. **Верхняя оценка для любого размещения.** Для любого допустимого размещения со значением $V$ справедливо $V \leq V_{IP} \leq V_{LP}$; следовательно, отношение $V_{LP}/V$ — верхняя оценка погрешности размещения относительно оптимума.

### Доказательство

**Разрешимость.** Релаксация является задачей линейного программирования: целевая функция линейна, ограничения линейны, число переменных $O(nm)$ и ограничений $O(n+m)$ полиномиально по входу. Линейное программирование разрешимо за полиномиальное время методом внутренней точки (Khachian, 1979; Grötschel–Lovász–Schrijver, 1988). ∎

**Верхняя граница.** Всякое допустимое целочисленное размещение является частным случаем допустимого дробного: если задача размещена на $l$ процессорах, то $x_{i,l}=1$, а остальные $x_{i,l'}=0$; такое решение удовлетворяет всем ограничениям релаксации (равенство $\sum_l x_{i,l}=1 \le 1$ и неравенство бюджета выполнены). Следовательно, множество допустимых решений целочисленной задачи содержится в множестве допустимых решений релаксации, а максимум по большему множеству не меньше максимума по меньшему: $V_{LP} \geq V_{IP}$. ∎

**Верхняя оценка для любого размещения.** Любое допустимое размещение $x$ допустимо и для целочисленной задачи в смысле ограничений (но не обязательно целочисленно); его значение не превосходит оптимума $V_{IP}$, а тот, по пункту 2, не превосходит $V_{LP}$. Отсюда $V \leq V_{IP} \leq V_{LP}$. Если размещение получено округлением дробного решения релаксации со значением близким к $V_{LP}$, то его погрешность ограничена разрывом между $V_{LP}$ и $V_{IP}$ (integrality gap). Это и есть верхняя оценка оптимума: планировщик получает гарантированную верхнюю границу $V_{LP}$ на достижимый оптимум, не требуя решения NP-трудной целочисленной задачи. ∎

## Теорема 3.2 (встроенная справедливость через квоты)

Добавление к ЛП-релаксации поквотных ограничений на владельцев

$$\sum_{i \in O_k} \sum_{l=1}^{m} x_{i,l} \cdot l \cdot p_i(l) \leq Q_k, \quad k = 1,\dots,n,$$

где $O_k$ — множество задач владельца $k$, а $Q_k$ — его квота, гарантирует, что каждое решение релаксации не превышает квоту владельца по суммарной занятой ёмкости; если при этом релаксация с квотными ограничениями разрешима, то существует допустимое (дробное) размещение, удовлетворяющее всем квотам.

### Доказательство

Квотное ограничение представляет собой линейное ограничение по переменным $x_{i,l}$, добавленное к релаксации без изменения линейности и числа переменных. Разрешимость сохраняется: множество допустимых решений сужается, но остаётся полиэдром, и задача по-прежнему решается за полиномиальное время. Для всякого допустимого решения суммарная ёмкость, занятая задачами владельца $k$, равна левой части квотного ограничения и, следовательно, не превосходит $Q_k$ — квота не нарушена. Если релаксация с квотными ограничениями разрешима, найденное решение есть допустимое размещение, уважающее квоты всех владельцев.

Связь с гарантией справедливой доли (раздел 3.3) состоит в следующем: если квоты $Q_k$ заданы так, что их суммарное применение совместно с ограничением бюджета $\sum_k Q_k \ge C$ не «съедает» спрос, то допустимость релаксации с квотами означает, что справедливую долю $A_k \ge \min(FS_k, D_k)$ можно достичь на уровне дробного решения; необходимое условие — $\sum_k \min(FS_k, D_k) \le C$ (см. файл `proof-minimal-deficit-fairness.md`, шаг 1). Целочисленность и гарантия в пределах спроса требуют дополнительного округления, которое, как отмечено в §3.5, в данной постановке (максимизация взвешенного объёма над политопом частичного размещения) не наследует разреженности ЛП из [[18-jansen-zhang|18]] и выносится за рамки релаксации. ∎

## Обсуждение

1. **Ценность верхней оценки.** В пакетном режиме планировщик получает не только размещение, но и верхнюю границу $V_{LP}$ на оптимум — то, что невозможно при чисто эвристическом размещении. Это делает ЛП-подход инструментом с доказуемой оценкой качества.
2. **Границы применимости округления.** Верхняя оценка $V_{LP}$ корректна всегда; количественная погрешность конкретного округления зависит от integrality gap и требует отдельного обоснования, что отражено в §3.5.
3. **Эталон цены округления.** Аналогичный каркас «ЛП-релаксация + округление» с доказанной ценой округления (не более одного времени обработки $t$ на машину) для задачи $R \parallel C_{\max}$ дан в работе Ленстры–Шмойса–Тардоса [[78-lenstra-shmoys-tardos|78]]; там же установлена нижняя граница $3/2$ при $P \ne NP$. Для рассматриваемой здесь постановки максимизации взвешенного объёма гарантированное округление с константной ценой не доказано и остаётся открытым, что ограничивает область применения.
