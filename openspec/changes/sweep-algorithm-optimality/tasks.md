# Задачи исправления заявления об оптимальности «алгоритма заметания» (гл. 4 §4.2–4.3)

## 1. Подтверждение дефекта контрпримером

- [ ] 1.1 Перечитать `draft/05-chapter-4-algorithms/README.md` §4.2–4.3: зафиксировать целевую функцию `max Σ c_i x_i`, ограничения `Σ x_i ≤ C`, `x_i ∈ {0} ∪ [x_min, x_max]`, и заявление «жадное размещение по убыванию приоритета является оптимальным».
- [ ] 1.2 Проверить контрпример: `C=100`, задача A `(c=100, x_min=40, x_max=100)`, задача B `(c=95, x_min=60, x_max=60)`. Алгоритм даёт `x_A=40, x_B=60`, значение `9700`; оптимум `x_A=100, x_B=0`, значение `10000`. Подтвердить `9700 < 10000`.
- [ ] 1.3 Зафиксировать причину: нижняя граница `x_min` делает задачу непрерывной задачей о ранце с «порогом» включения; жадное заполнение всех `x_min` по `c_i` принудительно тратит ёмкость на задачи с меньшим `c_i`.
