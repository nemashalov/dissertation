# Задачи исправления «седловой задачи» для справедливого распределения (гл. 3 §3.3)

## 1. Подтверждение дефекта

- [ ] 1.1 Перечитать `draft/04-chapter-3-model/README.md` §3.3: зафиксировать формулировку `max_i min_{-i} allocated_i/capacity_i` и утверждение об обобщении DRF [8].
- [ ] 1.2 Проверить, что нотация `min_{-i}` не определена в спеках нотации (`specs/notation-model.md`, `specs/terminology-table.md`) и что аргумент `allocated_i/capacity_i` не зависит от переменной, по которой берётся минимум.
- [ ] 1.3 Сверить с [8] (Ghodsi et al., Dominant Resource Fairness): DRF — max-min по доминантным долям, а не седловая задача `max_i min_{-i}`.
