# Задачи уточнения утверждения о паузах поколенческой сборки мусора (гл. 4 §4.5.1)

## 1. Проверка первоисточника

- [x] 1.1 Перечитать `draft/05-chapter-4-algorithms/README.md` §4.5.1 и найти утверждение «именно поколенческие схемы… обеспечивают на практике низкие паузы» со ссылкой [44].
- [x] 1.2 Сверить с `Uniprocessor Garbage Collection Techniques.pdf` (Wilson, 1992): подтвердить, что низкие паузы Уилсон приписывает **инкрементальным** сборщикам (дословно: «Incremental techniques can keep garbage collection pause times short»), а о поколенческих говорит как о смягчающих проблему пауз, при этом полные сборки могут давать существенно более длинные паузы (§2.7).

## 2. Правка текста

- [x] 2.1 Переформулировать тезис §4.5.1: низкие паузы дают инкрементальные сборщики; поколенческие схемы лишь аллевиируют паузы (чаще собирают малую область), но полные сборки могут быть длиннее.
- [x] 2.2 Выверить ссылку [44]: не приписывать Уилсону тезис о «низких паузах» поколенческих схем в такой форме; прямо сослаться на §2.7 (длинные паузы полных сборок).
- [x] 2.3 Убедиться, что правка не подрывает модель эластичности по памяти (снижение `x_min` сборщиком мусора) — уточнить, что выигрыш в эластичности не противоречит описанным паузам.
